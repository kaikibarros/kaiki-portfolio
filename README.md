# 💼 Kaiki Portfolio

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e experiências como desenvolvedor.

## 🚀 Sobre o projeto

Este projeto foi criado com o objetivo de reunir em um só lugar:

- minha apresentação profissional
- minhas principais habilidades técnicas
- projetos desenvolvidos
- informações de contato

A proposta do portfólio é transmitir uma identidade visual moderna, responsiva e profissional, com suporte a tema claro e escuro.

---

## 🛠️ Tecnologias utilizadas

- React
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

---

## 🎨 Funcionalidades

- Responsive layout
- Light and dark theme
- Seção de habilidades
- Seção de projetos
- Seção de contato
- Background personalizado com identidade visual dinâmica
